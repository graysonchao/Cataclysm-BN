================================================================================
MISSION SYSTEM ARCHITECTURE
================================================================================

Storage:
  - static std::unordered_map<int, mission> world_missions
  - Missions stored by unique ID (uid)
  - IDs assigned sequentially via g->assign_mission_id()

Lifecycle:
  1. reserve_new() or reserve_random() creates mission object
  2. Mission assigned to NPC as mission giver
  3. assign(avatar) assigns to player, sets in_progress status
  4. wrap_up() or fail() completes mission lifecycle
  5. Mission retained in world_missions for history

Mission Types:
  - Defined in JSON data files
  - Lua can query but not create new types
  - 16+ built-in goal types (MGOAL_*)
  - 5 origin types (ORIGIN_*)
  - Callbacks: start, end, fail (defined in JSON)

================================================================================
LIMITATIONS & GAPS
================================================================================

CANNOT DO (API Gaps):
  1. Create new mission types from Lua (JSON-only)
  2. Modify missions after creation (target, deadline, rewards)
  3. Delete missions from world_missions (only fail/complete)
  4. Create custom mission goals dynamically
  5. Override mission-specific callbacks from Lua
  6. Directly access mission internal state (step counter, etc.)

WORKAROUNDS:
  1. Use existing mission types with reserve_new()
  2. Complete/fail missions instead of modifying
  3. Use fail() to effectively "remove" missions
  4. Use wrap_up() to force completion
  5. Create mission types in JSON with callback functions

================================================================================
PRACTICAL USAGE PATTERNS
================================================================================

Pattern 1: Simple Mission Creation
  local mission = game.Mission.reserve_new(
    game.MissionTypeIdRaw.new("MISSION_ID"),
    npc:get_id()
  )
  mission:assign(avatar)

Pattern 2: Random Mission at Location
  local mission = game.Mission.reserve_random(
    game.MissionOrigin.ORIGIN_ANY_NPC,
    avatar:global_omt_location(),
    npc:get_id()
  )
  if mission then mission:assign(avatar) end

Pattern 3: Mission Monitoring Loop
  for _, mission in ipairs(avatar:get_active_missions()) do
    if mission:in_progress() then
      gapi.add_msg(MsgType.neutral, mission:name())
    end
  end

Pattern 4: Mission Completion
  if mission:in_progress() then
    mission:wrap_up()  -- Success
  end

Pattern 5: Mission Failure
  if mission:in_progress() then
    mission:fail()     -- Failure
  end

Pattern 6: Multi-step Progress
  mission:step_complete(1)  -- Mark step 1 complete

Pattern 7: Query Mission Info
  local info = {
    name = mission:name(),
    id = mission:get_id(),
    desc = mission:get_description(),
    value = mission:get_value(),
    status = mission:in_progress()
  }
