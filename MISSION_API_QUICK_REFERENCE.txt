MISSION CREATION
================================================================================
Mission.reserve_new(type_id, npc_id) -> Mission
  Usage: local m = game.Mission.reserve_new(
           game.MissionTypeIdRaw.new("MISSION_BRING_ITEM"), 
           npc:get_id())
  Note: Mission assigned to NPC as giver, not player

Mission.reserve_random(origin, pos, npc_id) -> Mission*
  Usage: local m = game.Mission.reserve_random(
           game.MissionOrigin.ORIGIN_ANY_NPC,
           avatar:global_omt_location(),
           npc:get_id())
  Note: Returns nil if no suitable type found

MissionType.get_random_mission_id(origin, pos) -> MissionTypeIdRaw
  Usage: local type = game.MissionType.get_random_mission_id(
           game.MissionOrigin.ORIGIN_GAME_START,
           avatar:global_omt_location())

MISSION ASSIGNMENT TO PLAYER
================================================================================
Mission:assign(avatar) -> void
  Usage: mission:assign(gapi.get_avatar())
  Note: Only works on unassigned missions
  Effect: Sets in_progress status, initializes deadline, calls start callback

MISSION STATE CHANGES
================================================================================
Mission:wrap_up() -> void
  Effect: Set status to success, calls end callback, removes items
  Usage: mission:wrap_up()

Mission:fail() -> void
  Effect: Set status to failure, calls fail callback
  Usage: mission:fail()

Mission:step_complete(step) -> void
  Effect: Mark step as complete for multi-step missions
  Usage: mission:step_complete(1)

COMMON PATTERNS
================================================================================

Create and Assign Mission:
  local m = game.Mission.reserve_new(
    game.MissionTypeIdRaw.new("MISSION_ID"),
    npc:get_id()
  )
  m:assign(gapi.get_avatar())

Create Random Mission:
  local m = game.Mission.reserve_random(
    game.MissionOrigin.ORIGIN_ANY_NPC,
    gapi.get_avatar():global_omt_location(),
    npc:get_id()
  )
  if m then m:assign(gapi.get_avatar()) end

Check and Complete Mission:
  if m:in_progress() then
    if condition_met then
      m:wrap_up()
    else
      m:fail()
    end
  end

Iterate Player Missions:
  local avatar = gapi.get_avatar()
  for _, m in ipairs(avatar:get_active_missions()) do
    gdebug.log_info(m:name())
  end

LIMITATIONS
================================================================================

CANNOT:
  - Create new mission types from Lua (JSON-only)
  - Modify mission after creation (target, deadline, rewards)
  - Directly delete missions (only fail/complete)
  - Create custom mission goals dynamically
  - Override mission callbacks from Lua
  - Access internal mission state directly

CAN WORK AROUND BY:
  - Pre-define mission types in JSON
  - Use wrap_up() or fail() to manage lifecycle
  - Create chain missions using follow_up
  - Query all available missions and select dynamically

ERROR HANDLING
================================================================================

reserve_new() returns:
  - Valid Mission* pointer on success
  - Nothing throws exception, check nullptr

reserve_random() returns:
  - Valid Mission* pointer on success
  - nil if no suitable type found

assign() errors:
  - debugmsg() warning if already assigned
  - Does nothing if already assigned to another player

wrap_up() caveats:
  - Removes inventory items based on goal type
  - Only works on in_progress missions
  - Triggers item consumption for FIND_ITEM goals

  - Mission goal type
